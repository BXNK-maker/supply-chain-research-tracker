Abstract
Designing effective heuristics for diverse combinatorial optimization problems requires substantial expertise and repeated search. Large language models (LLMs) automate heuristic generation and refinement, but heuristic search typically depends on evaluation feedback from the problem being optimized. Generalizing to new problem definitions using only source-task feedback therefore remains a central challenge. We introduce MECo, an LLM-driven multi-task evolutionary framework for zero-shot cross-problem generalization. MECo maintains task-conditioned heuristic populations and uses a transfer gap based on cross-task population performance to guide their interactions. These interactions enable the transfer and recombination of heuristics. A complementary selection criterion then constructs a compact heuristic set by rewarding each member’s additional coverage of source combinations. The selected set is applied to target problems without further search or adaptation. Experiments on 32 problem variants across vehicle routing (VRP) and flexible job-shop scheduling (FJSP) show that MECo achieves the lowest mean costs compared with eight automated heuristic design (AHD) baselines under the same budgets. On out-of-domain problems, it outperforms the strongest baseline in each family. Moreover, integrating the framework of MECo with different AHD methods improves their ID and OOD performance in both families, supporting its effectiveness across different methods.

Introduction
Combinatorial optimization problems (COPs) arise in a wide range of logistics and manufacturing applications
(
Toth and Vigo, 2014
)
. Changes in operational requirements can introduce new problem variants, often requiring existing heuristics to be adapted or redesigned. This process demands domain expertise and repeated cycles of design and evaluation, making heuristic development a recurring cost. Large language models (LLMs) offer a promising way to reduce this burden through automated heuristic design (AHD)
(
Liu et al., 2026b
)
. Given a problem description and evaluation feedback, these methods iteratively generate and refine executable heuristics. We distinguish task-specific AHD, which designs heuristics for each problem independently, from cross-task AHD, which jointly develops heuristics for multiple problems. Figure
1
compares these design paradigms alongside our framework.
We define a task as the design of heuristics for a particular optimization problem. Task-specific AHD methods have made substantial progress in automating this process. Population-based evolutionary search combines LLM-driven program generation with fitness-based selection
(
Liu et al., 2024b
;
Romera-Paredes et al., 2024
)
. Reflection further guides program generation using performance feedback
(
Ye et al., 2024
)
. Other methods balance exploration and exploitation through diversity-oriented evolution with harmony-search refinement
(
Dat et al., 2025
)

Comparison of heuristic design paradigms. Unlike existing methods, MECo evolves a heuristic set for zero-shot cross-problem generalization.
or Monte Carlo tree search
(
Zheng et al., 2025
)
. These advances improve heuristic discovery within individual tasks. However, applying the same design framework to another problem typically requires another round of problem-specific search. Without systematic reuse of previously discovered heuristics, even closely related problems can incur repeated design costs.
Cross-task AHD addresses this repetition by jointly developing heuristics for multiple problems. MoH learns reusable heuristic optimizers
(
Shi et al., 2026
)
, while MTHS jointly evolves general-purpose metaheuristics and task-specific programs
(
Liu et al., 2026c
)
. However, jointly designing heuristics for multiple problems does not ensure that the resulting programs can be applied directly to new problems without additional search. In practice, operational requirements can be combined in many ways, and each new combination can define a distinct optimization problem. This creates a potentially large family of related design tasks. If each new task requires a fixed search budget, the total design cost grows with the number of tasks. Moreover, evaluation data for new combinations may be unavailable. This motivates designing heuristics using feedback from a limited set of source tasks and applying them directly to new problems without additional heuristic search.
To address this challenge, we propose MECo, an LLM-driven framework that uses
M
ulti-task
E
volution through task
Co
mbination to enable zero-shot cross-problem generalization. Starting from source tasks, MECo progressively develops new populations for combined task specifications. Their offspring inherit and adapt parent heuristics through evolutionary operators designed for cross-task knowledge transfer. These offspring are evaluated separately on the available datasets, allowing joint feedback to guide heuristic design for combined problems without accessing their instances. To guide interactions among the growing collection of populations, a task transfer gap measures how well the heuristics from one population perform on the sources associated with another. MECo uses this measure to favor compatible parent tasks while exploring new combinations. Finally, it selects a small set from all task populations according to the complementary performance of its members across combinations of sources. Both evolution and set selection rely exclusively on source data, and the selected programs are applied to target problems without further search or adaptation.
Our contributions are summarized as follows.
•
We introduce MECo, a multi-task evolutionary framework that develops complementary heuristics for zero-shot cross-problem generalization using source task feedback alone.
•
We introduce a population-level transfer gap to quantify empirical task compatibility and guide heuristic transfer between task populations.
•
Experiments on 32 variants across vehicle routing (VRP) and flexible job-shop scheduling (FJSP) show lower mean costs on unseen problems than eight AHD baselines under matched proposal budgets. Integrating the framework with three existing AHD methods further improves their performance.

Generalization Through Joint Training
Joint source training can yield stronger heuristics for a combined problem than separate source training. We illustrate this phenomenon in VRP, where O, TW, B, and L label constraint attributes. Two parent populations evolve on their respective source datasets. 4.1
Experimental setup
Problem setup.
We study vehicle routing problem (VRP) and flexible job-shop scheduling problem (FJSP). The base VRP is the capacitated vehicle routing problem (CVRP), which serves every customer using depot-to-depot routes subject to vehicle capacity and minimizes total travel distance. The base FJSP assigns each operation to an eligible machine and sequences operations to minimize makespan, subject to within-job precedence and machine availability. For VRP, the designed heuristic selects the next customer during route construction. For FJSP, it selects the next operation and its machine from feasible assignments.
We construct 16 variants per family by activating subsets of 4 optional constraints. VRP uses open routes (O), backhauls (B), time windows (TW), and route-length limits (L), following multi-task VRP formulations
(
Liu et al., 2024a
)
. FJSP uses release dates (R), assembly precedence (A), sequence-dependent setups (S), and transport lags (T)
(

;
Lin et al., 2022
;
Shen et al., 2018
;
Berterottière et al., 2024

4.4
Component ablations
We study the importance of task pairing and heuristic evolution operators in MECo by evaluating five ablation settings against the complete framework. The condition without transfer gap replaces guided task-pair selection with uniform random sampling, while the remaining four conditions individually omit mechanism composition, conflict resolution, exploratory crossover, or transfer-oriented mutation across all evolutionary stages. As shown in Table
4
, removing any single component degrades overall solution quality, leading to higher mean costs across both problem families on both ID and OOD tasks. Specifically, omitting transfer gap guidance and transfer-oriented mutation leads to the largest performance drops on VRP. On FJSP, removing exploratory crossover yields the highest makespan while also introducing substantial run-to-run variance. In addition, full MECo consistently maintains lower standard deviations than the ablated variants, indicating that the full pipeline provides more reliable optimization. Together, these results confirm that guided task pairing and the specialized operators work together to achieve MECo’s strong generalization across diverse problem domains.

This work introduces MECo, an LLM-driven multi-task evolutionary framework for zero-shot cross-problem generalization. Transfer gaps guide interactions among task populations, enabling heuristics to be adapted and recombined. Source feedback supports both evolution and complementary set selection, without target evaluations during design. Experiments on VRP and FJSP demonstrate improved ID and OOD performance under a shared design budget. Moreover, integrating MECo with EoH, ReEvo, and HSEvo consistently improves their performance. Together, these results support coordinated multi-task search as an effective approach to designing heuristic sets that generalize beyond their source problems.

A.1
Task-specific automated heuristic design
LLM-driven AHD commonly uses evolutionary search to generate and refine executable heuristics from problem-specific feedback
(
Romera-Paredes et al., 2024
;
Liu et al., 2024b
;
Van Stein and Bäck, 2024

. Natural-language descriptions and reflection provide additional guidance for program evolution
(
Liu et al., 2024b
;
Ye et al., 2024
)
. Other search strategies include diversity-aware evolution
(
Dat et al., 2025
)
, Monte Carlo tree search
(
Zheng et al., 2025
)
, and neighborhood search
(
Xie et al., 2025b
)
. These approaches differ primarily in how they explore the program space and reuse evaluation feedback.
A complementary direction addresses variation among instances of the same problem. Heuristic-set evolution
(
Liu et al., 2026a
)
and instance specialization through feature-based partitioning or performance-based clustering
(
Zhang et al., 2025a
;
Hu et al., 2026
)
seek complementary strengths across instance groups. Multi-objective search additionally considers trade-offs between solution quality and computational cost
(
Yao et al., 2025
)
. Applications extend to parameter adaptation and ruin-operator design within vehicle-routing solvers
(
Xie et al., 2025a
;
Xie et al., 2026
)
, as well as algebraic turbulence-model discovery
(
Zhang et al., 2025b
)
.
A.2
Cross-task automated heuristic design
Cross-task AHD investigates reusable knowledge beyond an individual design task. Existing approaches transfer task-agnostic algorithmic templates through hierarchical representations
(
Liu et al., 2026c
)
, learn heuristic optimizers through meta-optimization
(
Shi et al., 2026
)
, or share program archives before task-specific adaptation
(
Gozeten et al., 2026
)
. The reusable knowledge consequently ranges from abstract search principles to executable programs, with downstream feedback guiding their specialization.
A.3
Knowledge transfer across optimization tasks
Knowledge transfer across optimization tasks has also been studied through learned solvers and shared search populations. In neural combinatorial optimization, multi-task VRP learning trains a shared solver across problem definitions and studies zero-shot transfer to unseen constraint combinations
(
Liu et al., 2024a
;
Zhou et al., 2026
;
Chen et al., 2026
)
. Evolutionary multitasking exploits shared representations and cross-task reproduction, with adaptive transfer mechanisms regulating exchange as populations develop
(
Gupta et al., 2015
;
Bali et al., 2019
)
. The usefulness of such an exchange motivates studying task relationships. Related work in representation learning characterizes these relationships through Fisher-information embeddings
(
Achille et al., 2019
)
and directed transfer graphs estimated from predictive performance
(
Zamir et al., 2018
)
, distinguishing representational similarity from empirical transfer utility.

EoH and ReEvo rank their final populations by mean normalized source cost. MCTS-AHD applies the same ranking to feasible programs in its search tree, and HSEvo uses its valid-program archive and final population, including numerical variants. Each selects the best distinct programs up to the prescribed set size.
EoH-S greedily adds the program that most reduces the sum of per-instance best-member losses, starting with the program of lowest mean loss. MEoH pools its final population and elitist archive, ranks candidates in descending order of its native dominance-dissimilarity survival score, and selects four programs. A predetermined random ordering resolves score ties. This four-member extraction adapts the native scoring principle to our common evaluation protocol.
EMO-STA selects each source’s final adapted program, and MoH selects each source’s best heuristic with its associated optimizer. All selections use training feedback alone.

All final programs are selected using target training feedback, and Best4 is computed only after selection. The entries report means and sample standard deviations over three searches. Average rank is the mean of the two target ranks among all listed methods, with ties assigned midranks at the displayed precision. EMO-STA uses its native scoring mechanism. Although MECo does not achieve the lowest cost on either target, its costs remain close to the best observed values and it achieves the best average rank. Moreover, MECo uses half as many additional proposals as the task-specific baselines, demonstrating more efficient use of the adaptation proposal budget.
