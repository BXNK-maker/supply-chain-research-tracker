# Tailoring Optimization Approaches with Domain Knowledge in Industry Process for Meta-heuristic Development

**Authors**: Jakub Cebula, Konrad Gmyrek, Paweł B. Myszkowski, Marko Ðurasević, Łukasz P. Olech, Adam Paliszek-Saładyga
**Date**: 2026-11-10
**Paper ID**: [openalex:2611.13940](https://arxiv.org/abs/2611.13940)

## Summary

The paper introduces the Industry Process for Meta-heuristic Development (IPMD) schema, a systematic methodology for designing meta- and hyper-heuristic applications for optimization problems. As a case study, the authors apply Balancing Non-dominated Tournament Genetic Programming (BNTGP)—a genetic programming-based hyper-heuristic—to solve two NP-hard multi-objective optimization problems: the Capacitated Vehicle Routing Problem with Time Windows and the Multi-Skill Resource Constrained Project Scheduling Problem. This approach enables the exploration of heuristic search spaces to generate reusable rules across problem instances.

## Key Contributions

- Introduces the Industry Process for Meta-heuristic Development (IPMD) schema as a systematic methodology for applying meta- and hyper-heuristics to optimization problems.
- Presents Balancing Non-dominated Tournament Genetic Programming (BNTGP) as a genetic programming-based hyper-heuristic for multi-objective optimization.
- Demonstrates the application of BNTGP to two NP-hard multi-objective optimization problems: the Capacitated Vehicle Routing Problem with Time Windows and the Multi-Skill Resource Constrained Project Scheduling Problem.
