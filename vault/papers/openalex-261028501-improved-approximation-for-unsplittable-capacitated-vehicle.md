# Improved Approximation for Unsplittable Capacitated Vehicle Routing Using Quota Trees

**Authors**: Zhenyu Wang
**Date**: 2026-10-20
**Paper ID**: [openalex:2610.28501](https://arxiv.org/abs/2610.28501)

## Summary

The paper investigates the Unsplittable Capacitated Vehicle Routing Problem (UCVRP), a fundamental routing problem combining metric TSP and bin packing difficulties. The author develops a deterministic (5/2 + epsilon)-approximation algorithm for UCVRP with general capacity and arbitrary positive demands running in polynomial time for fixed epsilon. The method uses endpoint quota trees, demand rounding, local search, matching, set packing, and weighted graphic matroid parity to construct and combine disjoint routes.

## Key Contributions

- Proposes a deterministic (5/2 + epsilon)-approximation algorithm for the Unsplittable Capacitated Vehicle Routing Problem (UCVRP) running in n^{O(1/epsilon)} time.
- Handles general capacity and arbitrary positive demands through local search combined with endpoint quota trees, matching, set packing, and weighted graphic matroid parity.
